## Projetos em destaque

### [StockCore API](https://github.com/ruangdev0-ux/stockcore-api) · C# e .NET 8
API REST de controle de estoque em camadas: entradas e saídas, estornos, estoque mínimo, alertas, relatórios e controle de concorrência.
Stack: C#, .NET 8, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, JWT, FluentValidation, xUnit e GitHub Actions. 90 testes (44 unitários e 46 de integração) validados no CI.
[Documentação da API](https://ruangdev0-ux.github.io/stockcore-api/) · [Repositório](https://github.com/ruangdev0-ux/stockcore-api)

### [TeamTasks API](https://github.com/ruangdev0-ux/teamtasks-api) · TypeScript e Node.js
API REST com usuários, equipes, projetos e tarefas: papéis e permissões, fluxo de status, histórico de alterações, filtros e paginação.
Stack: TypeScript, Node.js, Express, PostgreSQL, Drizzle ORM, JWT, Zod, Vitest e GitHub Actions. 70 testes (35 unitários e 35 de integração) validados no CI.
[Documentação da API](https://ruangdev0-ux.github.io/teamtasks-api/) · [Repositório](https://github.com/ruangdev0-ux/teamtasks-api)

### [SalesFlow](https://github.com/ruangdev0-ux/salesflow) · JavaScript

[Demonstração](https://ruangdev0-ux.github.io/salesflow/) · [Repositório](https://github.com/ruangdev0-ux/salesflow)

### [SkyCast](https://github.com/ruangdev0-ux/skycast) · JavaScript e API REST
